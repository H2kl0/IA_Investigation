Cómo Conectaron Cada Objetivo con su Método

Objetivo 1: ¿La IA realmente ayuda a crear programas?
Método: Estudios + casos reales (Duolingo +25% velocidad; Microsoft uso obligatorio)
Objetivo 2: ¿Qué tan fácil y rápido es?
Método: Encuestas (3.7/5 eficiencia) + GitHub Copilot (55% más rápido)
Objetivo 3: ¿La calidad del código es buena?
Método: Casos + literatura — 46% del código ya usa IA
Objetivo 4: ¿Qué oportunidades y problemas hay?
Método: Encuestas + análisis de limitaciones — Democratización vs. supervisión
Objetivo 5: ¿Qué consejos dar?
Método: Integraron los datos reales para formular recomendaciones

Lo Que Funcionó

  • Triangulación: Encuestas, casos y teoría se confirmaron entre sí.
  • Evidencia variada: Datos duros + análisis + opiniones.
  • Aplicabilidad: Información práctica que puede implementarse de inmediato.

La Jugada Maestra

  • Literatura: ¿Qué sabemos?
  • Casos reales: ¿Qué pasa en la práctica?
  • Encuestas: ¿Qué piensa la gente?

El Resultado

  • 90% cree que la IA es accesible sin saber código.
  • Empresas ya tienen resultados positivos.
  • La IA no reemplaza, potencia a los programadores.
